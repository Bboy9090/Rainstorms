# Rainstorms Illustration Examples

This folder contains sample images generated by or designed for Rainstorms storybook projects.

## Expected Image Assets

Once generated, this folder will include:

### Character Reference Sheets

Character reference sheets ensure visual consistency across all pages:

- **`beebot-reference.png`** — BeeBot character (Robot Emotions story)
- **`luna-reference.png`** — Luna character (Robot Emotions story)
- **`oliver-reference.png`** — Oliver character (Captain Blanket story)
- **`captain-blanket-reference.png`** — Captain Blanket persona (Captain Blanket story)

**Format:** 1024×1024 PNG
**Style:** Character turnaround or portrait with color palette, clothing details, and distinctive traits clearly visible

### Page Illustrations

Sample page spreads showing text + generated illustration:

- **`robot-emotions-page-03.png`** — BeeBot meets Luna in the workshop
- **`robot-emotions-page-08.png`** — BeeBot's first smile
- **`captain-blanket-page-05.png`** — Oliver transforms into Captain Blanket
- **`captain-blanket-page-09.png`** — The midnight brother appears

**Format:** 1792×1024 PNG (landscape page spread)
**Style:** Warm, whimsical children's book illustration matching the story tone

### Cover Art

Final book covers as they would appear in the Publishing Center:

- **`robot-emotions-cover.png`** — Cover art for the Robot Emotions book
- **`captain-blanket-cover.png`** — Cover art for the Captain Blanket book

**Format:** 1024×1536 PNG (portrait book cover aspect ratio)
**Style:** Eye-catching title treatment with main character and thematic elements

## Image Generation Notes

All illustrations are intended to be generated using:

- **OpenAI DALL·E 3** (via Rainstorms' built-in illustration engine)
- **Midjourney** (using exported prompts from Page Builder)
- **Stable Diffusion** (using exported prompts with custom models)

Rainstorms generates detailed, consistent illustration prompts that include:

- Character visual descriptions (pulled from Character Forge)
- Scene composition and layout guidance
- Lighting, mood, and style direction
- Age-appropriate content constraints
