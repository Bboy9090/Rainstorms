# Bobby's Story Bench — Brand Transition

## Public product name
**Bobby's Story Bench**

Legacy repository, URL, Expo slug, URL scheme, iOS bundle identifier, Android package identifier, database names, storage keys, and deployment identifiers remain unchanged during this transition.

## Product promise
Turn a story idea into a structured children's picture book: blueprint, characters, page text, illustration direction, consistency checks, and export.

## Icon master
- Primary symbol: an open children's book resting on a compact workshop-bench silhouette.
- Center detail: a single creation spark rising from the book gutter.
- Readability target: recognizable at 32 px without text.
- No gradients that disappear at small sizes; no fine page text; no character artwork embedded in the icon.
- Maintain a generous safe zone around the book/bench mark for Android adaptive cropping.

## Splash master
- Centered icon mark above the wordmark **Bobby's Story Bench**.
- Secondary line: **Build a little world, one page at a time.**
- Calm blank-page-to-illustrated-page visual progression; avoid busy character collages.
- Native splash must remain legible in portrait and tablet layouts.

## Required production exports
- 1024×1024 store icon master.
- Android adaptive foreground 1024×1024 plus flat background.
- iOS opaque 1024×1024 icon.
- 2732×2732 splash master with centered safe composition.
- Web favicon 512, 192, 64, 32.
- Transparent SVG source mark for documentation and marketing.

## Compatibility rule
Do not rename `com.rainstorms.app`, the Expo `rainstorms` slug/scheme, repo paths, existing API routes, or persisted storage/database identifiers as part of a visual-brand PR.
